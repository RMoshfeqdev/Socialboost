# SocialBoost | پنل مدیریت خدمات شبکه‌های اجتماعی

**پروژه شخصی رضا مشفق** · Node.js · Express · SQLite · JavaScript · HTML/CSS

SocialBoost یک نمونه‌کار وب فارسی برای نمایش جریان‌های کاری یک پنل خدمات شبکه‌های اجتماعی است؛ از مشاهده سرویس‌ها و ثبت سفارش تا مدیریت حساب، کیف پول، تراکنش‌ها و پشتیبانی.

> **وضعیت انتشار:** نسخه‌ی پورتفولیو / نمونه‌کار. این پروژه در وضعیت فعلی برای استفاده تجاری یا نگهداری اطلاعات واقعی کاربران آماده نیست. پیش از هر استقرار عمومی باید احراز هویت سمت سرور، مجوزدهی هر درخواست، حفاظت از عملیات مالی، اعتبارسنجی ورودی‌ها و آزمون امنیتی تکمیل شود.

## قابلیت‌های موجود در رابط

- صفحه معرفی و داشبورد خدمات
- فهرست سرویس‌ها و فرم ثبت سفارش
- صفحات سفارش‌ها، پروفایل، کیف پول و تراکنش‌ها
- بخش پشتیبانی و پیام‌ها
- رابط فارسی و راست‌چین
- اتصال سمت سرور به API ارائه‌دهنده سرویس (نیازمند کلید API شخصی در محیط اجرا)

## فناوری‌ها

- **Backend:** Node.js، Express.js
- **Database:** SQLite از طریق `node-sqlite3-wasm`
- **Frontend:** HTML5، CSS3، JavaScript خالص
- **Integration:** REST-style HTTP API و `fetch`
- **Password storage:** هش رمز عبور با `bcryptjs` در نسخه‌ی پورتفولیو

## راه‌اندازی محلی

نیازمندی: Node.js نسخه 20 یا جدیدتر.

```bash
npm install
cp .env.example .env
# در صورت نیاز، کلید جدید سرویس‌دهنده را فقط در فایل .env وارد کنید
npm start
```

سپس در مرورگر باز کنید: `http://localhost:3000`

اگر `MASTER_SMM_API_KEY` تنظیم نشده باشد، بخش‌هایی که به سرویس بیرونی وابسته‌اند در دسترس نخواهند بود. رابط و صفحات محلی برای بررسی طراحی قابل مشاهده‌اند.

## نکات امنیتی مهم

- هیچ دیتابیس، حساب آزمایشی، فایل پشتیبان، تاریخچه‌ی Git یا کلید محرمانه‌ای در این بسته قرار نگرفته است.
- کلید API فقط از متغیر محیطی `MASTER_SMM_API_KEY` خوانده می‌شود. هر کلیدی که قبلاً در کد یا فایل ارسالی افشا شده باید در پنل ارائه‌دهنده باطل و جایگزین شود.
- رمزهای جدید با `bcryptjs` هش می‌شوند؛ با این حال نسخه‌ی فعلی هنوز از شناسه‌ی کاربر ارسالی از سمت مرورگر برای برخی عملیات استفاده می‌کند و نشست امن و کنترل دسترسی کامل ندارد.
- افزایش موجودی و پرداخت واقعی باید فقط از مسیر درگاه معتبر و تأیید سمت سرور انجام شود. موجودی این پروژه را پول واقعی تلقی نکنید.
- به دلیل موارد بالا، **روی سرور عمومی با داده‌ی واقعی مستقر نکنید**. برای تبدیل به محصول واقعی به بازطراحی احراز هویت/مجوزدهی و بررسی امنیت نیاز است.
